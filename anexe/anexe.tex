\section{Comenzi Console Unreal Engine folosite în VR Museum}
\label{anexa:comenzi_console}

Pentru a permite personalizarea experienței vizuale de către utilizator în mediul VR, au fost utilizate mai multe comenzi Unreal Engine ce pot fi apelate direct prin consola integrată. Aceste comenzi permit ajustarea detaliată a calității grafice, performanței și nivelului de upscaling prin DLSS.

\subsection*{1. Calitate grafică generală (Scalability Groups)}
Calitatea grafică este controlată prin comenzile `sg.*`, unde fiecare categorie de efect vizual poate fi ajustată de la nivelul 0 (Low) la 4 (Cinematic).

\begin{itemize}
    \item \texttt{sg.ViewDistanceQuality}
    \item \texttt{sg.AntiAliasingQuality}
    \item \texttt{sg.PostProcessQuality}
    \item \texttt{sg.ShadowQuality}
    \item \texttt{sg.GlobalIlluminationQuality}
    \item \texttt{sg.ReflectionQuality}
    \item \texttt{sg.TextureQuality}
    \item \texttt{sg.EffectsQuality}
    \item \texttt{sg.FoliageQuality}
    \item \texttt{sg.ShadingQuality}
    \item \texttt{sg.LandscapeQuality}
\end{itemize}

Fiecare poate primi o valoare între 0 și 4:
\begin{itemize}
    \item 0 – Low
    \item 1 – Medium
    \item 2 – High
    \item 3 – Ultra
    \item 4 – Cinematic
\end{itemize}

\subsection*{2. Cadre pe secundă (FPS)}
Numărul maxim de cadre pe secundă poate fi limitat sau lăsat nelimitat prin comanda:
\begin{itemize}
    \item \texttt{t.MaxFPS}
\end{itemize}

Valori acceptate:
\begin{itemize}
    \item 60, 90, 120 – valori fixe recomandate pentru VR
    \item 0 – fără limitare (unlimited)
\end{itemize}

\subsection*{3. Activarea DLSS}
Pentru a activa sau dezactiva tehnologia DLSS:
\begin{itemize}
    \item \texttt{r.NGX.DLSS.Enable} – permite controlul binar al funcției
\end{itemize}

Valori:
\begin{itemize}
    \item 0 – dezactivat
    \item 1 – activat
\end{itemize}

\subsection*{4. Setări DLSS (Upscaling Quality)}
Rezoluția internă de redare este ajustată cu comanda:
\begin{itemize}
    \item \texttt{r.ScreenPercentage}
\end{itemize}

Aceste comenzi pot fi apelate în timpul rulării aplicației din consola UE (tasta ` sau ~) sau pot fi integrate în logica meniului interactiv din VR pentru a permite modificarea în timp real de către utilizator. Ele au fost implementate pentru a spori compatibilitatea aplicației cu diverse configurații hardware și pentru a optimiza experiența vizuală în funcție de preferințele utilizatorului.
